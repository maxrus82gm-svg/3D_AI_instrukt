## Как пополняем

- Один приём или одна история — один `.md`-файл с понятным названием.
- Записываем цель, рабочий текст запроса, результат и ограничения. То, что только предполагаем, явно помечаем как гипотезу.
- Удачный промпт сохраняем без потери старой версии; следующие опыты добавляем отдельной версией.
- По возможности прикладываем «до / после» и отмечаем, какая модель Meshy использовалась.
- Исходники ZBrush и тяжёлые STL/OBJ храним отдельно. Секретные ключи и токены в репозиторий не кладём.

Документы пока лёгкие и свободные по форме. Когда заметок станет много, можно будет договориться о более строгой структуре.
